# Changelog

## 0.1.0

First packaged release, installable from PyPI as `obelisk-ffb`.

- `obelisk` command with `--apply`, `--version`, `--print-udev-rule` and `--install-desktop`.
- Settings: Steering Range, Overall Gain, Overall Filter, Damper / Friction / Inertia / Spring Gain, Max Torque Mode, Center.
- Profiles with automatic apply on connect.

- Releases now include a `.deb`, an `.rpm` and a `PKGBUILD`. They install the udev rule and the app-menu entry system-wide.
